# API Software Development Kits (SDKs)

Software Development Kits (SDKs) simplify interaction with an API by providing pre-built libraries, tools, and documentation in specific programming languages. The [[../entities/tastytrade-open-api.md|tastytrade Open API]] supports both official and community-contributed SDKs.

## tastytrade SDKs
*   **Official SDKs**:
    *   **JavaScript**: For web-based or Node.js applications.
    *   **Postman Workspace**: A collection of API requests for easy testing and exploration within the Postman environment.
*   **Community SDKs**:
    *   **Python (tastyware/tastytrade)**: A popular community-maintained library for Python developers, facilitating integration with Python-based trading strategies and applications.

Using an SDK can significantly reduce development time and effort by abstracting away the complexities of direct HTTP requests, JSON parsing, and authentication flows.
