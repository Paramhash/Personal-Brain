# tastytrade Production Environment

The [[../entities/tastytrade.md|tastytrade]] Production Environment is the live environment for API interactions, separate from the [[./tastytrade-sandbox-environment.md|sandbox environment]].

## Base URL

The base URL for the production environment is `https://api.tastyworks.com`.

## Credentials

*   Production users require a separate set of credentials (username and password) from sandbox users.
*   **Password Reset:** To reset your production password, visit [tastytrade.com](https://tastytrade.com).
