# SimpleSession Data Model

The `SimpleSession` data model is used by the [[../concepts/market-sessions.md|Tastyworks Market Sessions API]] to return core session timing information, particularly when retrieving sessions for a date range. It provides a concise view of the market's open and close times without additional state or nested session details.
