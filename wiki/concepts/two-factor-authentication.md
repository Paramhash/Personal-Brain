# Two-Factor Authentication (2FA)

Two-Factor Authentication (2FA) is a security process in which a user provides two different authentication factors to verify themselves. It adds an extra layer of security beyond just a username and password, significantly reducing the risk of unauthorized access even if one factor is compromised.

## How 2FA Works

Typically, 2FA involves:

1.  **Something you know**: Your password.
2.  **Something you have**: A physical device like a smartphone or a hardware token.
3.  **Something you are**: A biometric factor like a fingerprint or facial scan (less common in general API contexts but part of broader 2FA).

When 2FA is enabled, after entering their password, the user is prompted to provide a second factor, such as:

*   A code generated by an authenticator app (e.g., Google Authenticator, Authy).
*   A code sent via SMS to their registered phone number.
*   A confirmation via a push notification to a trusted device.

## 2FA in tastytrade API Authorization

For sensitive operations or access to sensitive data, tastytrade requires customers to use 2FA when granting an application access to their account via [[../concepts/oauth2.md|OAuth2]].

### Sensitive Scopes Requiring 2FA:

*   `read`: Access to view account information.
*   `trade`: Ability to execute trades.

### Enabling 2FA for tastytrade Accounts:

Customers can enable 2FA for their tastytrade account by navigating to `My Profile | Security` on my.tastytrade.com and enabling either:

*   **Authenticator App**: Using an app like Google Authenticator to generate time-based one-time passwords (TOTP).
*   **SMS Authentication**: Receiving a one-time code via text message.

During the "Authorize with tastytrade" step of the OAuth2 flow, after entering their account credentials, the customer will be prompted to enter their 2FA code before access is granted to the application. This ensures that even if an attacker has a user's password, they cannot authorize an application without the second factor.

For more details on the tastytrade API OAuth2 integration, see [[../research/tastytrade-api-oauth2-integration.md|Tastytrade API OAuth2 Integration]].
