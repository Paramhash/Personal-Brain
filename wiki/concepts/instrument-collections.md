These collections allow users to query market hours and holidays relevant to particular types of financial instruments.

# Market Sessions API

The Market Sessions API, provided by [[../entities/tastyworks.md|Tastyworks]], offers endpoints to programmatically determine market open/close times, current market state, and trading holidays across various equities and futures exchanges. This API is essential for applications that need to understand when markets are active to avoid submitting orders during closed sessions or to schedule trading activities.

## Base URL
`https://api.tastyworks.com/market-time`

## Authentication
Requires a valid session token passed via the `Authorization` header.

## Key Capabilities
*   Retrieve session timings for specific dates or date ranges.
*   Determine the current [[../concepts/market-state.md|market state]] (e.g., Open, Closed, Pre-Market, After-Hours).
*   Access [[../concepts/trading-holidays.md|trading holidays]] and half-day schedules.
*   Support for different [[../concepts/instrument-collections.md|instrument collections]] (exchanges/market types).

## Instrument Collections
The API organizes endpoints by instrument collection, representing the exchange or market:
*   `Equity`: US equity and equity options markets (e.g., [[../entities/nyse.md|NYSE]], [[../entities/nasdaq.md|NASDAQ]]).
*   `CME`: [[../entities/cme-group.md|CME Group]] futures and futures options.
*   `CFE`: [[../entities/cboe-futures-exchange.md|Cboe Futures Exchange]] (VIX futures).
*   `Zero Hash CLOB`: [[../entities/zero-hash-clob.md|Cryptocurrency markets]] (available on sessions range endpoint only).

## Endpoints
The API provides a comprehensive set of [[../concepts/api-endpoints.md|endpoints]] for querying session information:

### General Endpoints
*   **Get Sessions for Date Range:** `GET /sessions`
    *   Retrieves session timings for a specified date range (max 9 months) across any instrument collection.
*   **Get Current Sessions (Multi-Collection):** `GET /sessions/current`
    *   Retrieves current session timings, state, and next/previous session details for one or more instrument collections in a single request.

### Equities Endpoints
*   **Get Current Equities Session:** `GET /equities/sessions/current`
*   **Get Next Equities Session:** `GET /equities/sessions/next`
*   **Get Previous Equities Session:** `GET /equities/sessions/previous`
*   **Get Equity Holidays:** `GET /equities/holidays`

### Futures Endpoints
*   **Get Current Futures Sessions (All Exchanges):** `GET /futures/sessions/current`
*   **Get Current Futures Session by Exchange:** `GET /futures/sessions/current/{instrument_collection}`
*   **Get Next Futures Session by Exchange:** `GET /futures/sessions/next/{instrument_collection}`
*   **Get Previous Futures Session by Exchange:** `GET /futures/sessions/previous/{instrument_collection}`
*   **Get Futures Holidays by Exchange:** `GET /futures/holidays/{instrument_collection}`

## Data Models
The API utilizes several [[../concepts/data-models.md|data models]] to structure its responses:
*   [[../concepts/simplesession-data-model.md|SimpleSession]]: Basic session timing fields.
*   [[../concepts/currentsession-data-model.md|CurrentSession]]: Current session details, market state, and nested next/previous sessions.
*   [[../concepts/nextsession-data-model.md|NextSession]]: Details for an upcoming session.
*   [[../concepts/previoussession-data-model.md|PreviousSession]]: Details for a past session.
*   [[../concepts/marketcalendar-data-model.md|MarketCalendar]]: Contains market holidays and half-days.

All session objects share common time fields: `start-at`, `open-at`, `close-at`, `close-at-ext` (extended hours close), and `instrument-collection`.

## Important Considerations
*   All timestamps returned by the API are in [[../concepts/utc-timestamps.md|UTC]].
*   Futures markets operate nearly 24 hours a day, with specific daily breaks.
*   The `close-at-ext` field is relevant for [[../concepts/extended-hours-trading.md|extended hours trading]].
