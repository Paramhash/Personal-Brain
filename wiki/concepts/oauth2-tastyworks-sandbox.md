# OAuth2 (Tastyworks Sandbox)

OAuth2 is an industry-standard protocol for authorization. Within the [[./sandbox-environment.md|Tastyworks Sandbox Environment]], OAuth2 is fully supported for managing API access.

## Usage in Sandbox

*   **Application Management**: Users can create and manage their personal OAuth2 applications using tools provided within the sandbox interface, accessible after logging in with a sandbox user.
*   **Client Secret**: Upon initial creation of an OAuth2 application, the client secret is displayed only once. Users are advised to record it securely. If the client secret is lost, it cannot be retrieved and must be regenerated.
