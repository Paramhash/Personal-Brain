# tastytrade Open API Documentation

This document serves as the primary source of information for the [[../entities/tastytrade-open-api.md|tastytrade Open API]]. It provides comprehensive details for developers, fintech platforms, algorithmic traders, and AI/LLM applications looking to integrate with the tastytrade brokerage platform.

## Key Sections Covered
*   **Overview**: Introduction to the API, its purpose, and core capabilities.
*   **Getting Started**: Quickstart guides, sandbox environment details, and SDK information.
*   **Authentication**: Detailed explanation of [[../concepts/oauth2-authentication.md|OAuth2 authentication]] using bearer tokens.
*   **Trading**: Information on [[../concepts/api-order-management-tastytrade.md|order submission]], order flow, and order management.
*   **Streaming**: Guides for [[../concepts/api-streaming-data-tastytrade.md|real-time market data and account updates]] via WebSockets.
*   **API Reference (Open API Spec)**: Detailed endpoint specifications for various domains including:
    *   Account Status, Balances, and Positions
    *   Instruments and [[../concepts/api-symbology-tastytrade.md|Symbology]]
    *   [[../concepts/api-backtesting-tastytrade.md|Backtesting]]
    *   [[../concepts/api-margin-requirements-tastytrade.md|Margin Requirements]]
    *   Market Data, Metrics, and Sessions
    *   Orders, Transactions
    *   [[../concepts/api-watchlists-and-alerts-tastytrade.md|Watchlists and Quote Alerts]]
*   **API Guides**: Consolidated workflows for common API tasks.

The documentation emphasizes REST/JSON conventions, API versioning, error handling, and specific [[../concepts/api-symbology-tastytrade.md|symbology]] used by tastytrade. It is an essential resource for anyone developing solutions on the tastytrade platform.
