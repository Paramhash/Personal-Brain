# Order Submission Guide

The "Order Submission Guide" is an external reference document that provides detailed instructions and best practices for structuring and submitting trading orders.

This guide is specifically mentioned as a resource for understanding how to structure an order for both the [[../concepts/order-dry-run.md|Order Dry Run]] and [[../concepts/submit-order.md|Submit Order]] endpoints.
