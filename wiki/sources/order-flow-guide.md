# Order Flow Guide

The "Order Flow Guide" is an external reference document that provides comprehensive information on the lifecycle of a trading order, including its various [[../concepts/order-status.md|statuses]] and transitions.

This guide is specifically referenced for understanding "terminal order statuses," which are states where an order can no longer be cancelled or modified, as discussed in the context of [[../concepts/cancel-order.md|Cancel Order]] functionality.
