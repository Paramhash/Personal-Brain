# Quote Alerts

Quote Alerts are a type of notification system designed to inform users when a specific market data field for a financial instrument crosses a predefined [[../concepts/threshold.md|threshold]]. These alerts are commonly used in [[../concepts/trading.md|trading]] and investment to monitor price movements, volatility changes, or other key metrics without constant manual observation.

## How They Work

A typical quote alert system allows a user to specify:

1.  **Symbol:** The financial instrument to monitor (e.g., a stock like `AAPL`, an ETF like `SPY`, or a future like `/ESM6`).
2.  **[[../concepts/market-data-fields.md|Market Data Field]]:** The specific data point to track. Common fields include:
    *   `Last`: The last traded price.
    *   `Bid`: The highest price a buyer is willing to pay.
    *   `Ask`: The lowest price a seller is willing to accept.
    *   `IV`: [[../concepts/implied-volatility.md|Implied Volatility]], particularly relevant for options.
3.  **Operator:** A comparison operator, typically `>` (greater than) or `<` (less than), to define the condition for triggering the alert.
4.  **[[../concepts/threshold.md|Threshold]]:** The specific value that, when crossed by the market data field, will trigger the alert.

## Common Use Cases

Quote alerts are versatile and can support various trading strategies:

*   **Price Breakout Alerts:** Setting an alert for `field: "Last"` and `operator: ">"` to get notified when a stock breaks above a resistance level, indicating potential upward momentum.
*   **Dip Buying Triggers:** Using `operator: "<"` to monitor for a stock dropping below a target entry price, signaling a potential buying opportunity.
*   **[[../concepts/implied-volatility.md|Implied Volatility]] Expansion Alerts:** Setting `field: "IV"` with `operator: ">"` on an options underlying to get notified when implied volatility spikes. This can be useful for timing premium-selling entries, as high IV often correlates with higher option prices.
*   **Bid/Ask Monitoring:** Using `field: "Bid"` or `field: "Ask"` to monitor specific sides of the market. This can be valuable for timing [[../concepts/limit-order.md|limit order]] placements, especially in less liquid markets.

## Alert Lifecycle

Quote alerts typically follow a [[../concepts/alert-lifecycle.md|defined lifecycle]] from creation to completion or expiration.

## Characteristics

*   **User-Scoped:** Alerts are generally tied to the authenticated user rather than a specific trading account, allowing for consistent monitoring across a user's various accounts or profiles.
*   **One-Shot:** Many alert systems, including the [[../entities/tastyworks-quote-alerts-api.md|Tastyworks Quote Alerts API]], are "one-shot." This means an alert triggers once and then enters a completed state. To monitor continuously, a new alert must be created after each trigger.

## Example Implementation

The [[../entities/tastyworks-quote-alerts-api.md|Tastyworks Quote Alerts API]] is an example of a system that provides this functionality, allowing programmatic management of such alerts.
