# tastytrade

tastytrade is a financial brokerage and technology platform that provides tools and services for active traders, particularly focusing on options and futures trading.

The platform offers an API that allows users to programmatically interact with their accounts, including submitting and managing orders.

## Key API Functionality

*   [[../concepts/order-submission.md|Order Submission]]: Programmatically send various types of trading orders (e.g., Limit, Market, Stop, Complex) for different instrument types.
*   Account Management: Access account details, positions, and balances.
*   Market Data: Retrieve real-time and historical market data.
*   Instrument Lookup: Find symbols and details for various tradable instruments.
