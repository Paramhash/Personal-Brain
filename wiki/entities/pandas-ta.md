# pandas-ta

`pandas-ta` is a Python library built on top of Pandas, providing a comprehensive collection of technical analysis indicators. It is designed to be easy to use and integrate with Pandas DataFrames.

## Usage in Zero-Cost Feature Engineering
In the [[../concepts/zero-cost-feature-engineering.md]] framework, `pandas-ta` is instrumental for performing the mathematical transformations required to generate the various features from raw End-of-Day data. It simplifies the calculation of indicators such as:
*   [[../concepts/downside-semi-variance.md]]
*   [[../concepts/chaikin-money-flow.md]]
*   [[../concepts/stochastic-rsi.md]]

By utilizing `pandas-ta`, the feature engineering process becomes efficient and robust, relying entirely on free data sources.
