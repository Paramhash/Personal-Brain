# Postman

[[../entities/postman.md|Postman]] is a popular API platform for building and using APIs. It provides a user-friendly interface for sending HTTP requests, testing APIs, and managing API collections.

## tastytrade Integration

[[../entities/tastytrade.md|tastytrade]] offers a public Postman workspace that developers can use to start sending API requests to their [[../concepts/tastytrade-sandbox-environment.md|sandbox environment]]. This workspace can be a valuable resource for exploring the API and understanding its structure without writing code.
