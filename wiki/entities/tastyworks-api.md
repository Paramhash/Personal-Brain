# Tastyworks API

The Tastyworks API provides programmatic access to the Tastyworks trading platform, allowing developers to build custom applications for trading, market data, and account management. It encompasses various services, including symbol search, instrument data, quotes, order placement, and account information.

Key components of the Tastyworks API include:
*   [[../entities/tastyworks-symbol-search-api.md|Symbol Search API]]: For looking up financial instruments by symbol.
*   [[../entities/tastyworks-instruments-api.md|Instruments API]]: For detailed instrument data, such as tick sizes, option chains, and futures products.
*   Other APIs for quotes, orders, and account management (not detailed in this source).

All API interactions generally require [[../concepts/api-authentication.md|API Authentication]] using a valid session token.
