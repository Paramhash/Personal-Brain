# DXLink

DXLink is the [[WebSocket API]] provided by [[Tastyworks]] for real-time, continuous streaming market data.

It serves as an alternative to the [[Market Data API (Tastyworks)|Market Data API]], which provides point-in-time snapshots rather than continuous streams. DXLink requires a quote token obtained from `GET /api-quote-tokens`.
